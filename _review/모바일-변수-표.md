# 모바일 변수 표 (작성 중)

모바일 전용 Figma 변수 파일에 만들 변수를 층 순서로 적는다. 관례는 `_review/변수-구조-관례.md`를 따른다. 단계별로 확인받은 뒤 다음 층을 적고, 마지막에 Define ID 표(엑셀)로 옮긴다.

- 열: Figma 이름 · 라이트 · 다크 · 출력 이름(WEB, 넥사크로로 나가는 것만) · 지금 코드(우리 토큰·쓰는 곳)
- `→` 는 다른 변수를 이어받는다는 뜻이다.
- 지금 코드에 다크 규칙이 없던 자리의 다크 값은 기존 다크 색(바탕 #121316, 카드 #1c1d21, 입력 칸 #3a3c43, 글자 #e6e7ea, 메인 #7aa2ff 등)에 맞춰 임시로 채운 값이다. 세부 색은 뒤에 따로 검토한다(사용자 결정 2026-11-06).

## 4-2. 버튼 변형 클래스 `classbtn/` (출력 이름 없음)

Vtheme처럼 기본 버튼(`button/`)과 모양이 다른 버튼만 클래스로 두고, 달라지는 자리만 적는다. 크기(큰·중간·작은)는 색 변수와 관계없으므로 같은 색이면 같은 클래스다(예: 시간 선택 '확인'은 `submit-btn`과 색이 같다). 변형 클래스는 Vtheme과 같이 출력 이름을 두지 않는다.

- 접두사(사용자 결정 2026-11-06): 한 프레임에서만 쓰는 클래스는 그 프레임 접두사(`WF-` · `POP-`)를 붙이고, 여러 프레임에서 같은 모양으로 쓰는 클래스는 접두사 없이 둔다. Vtheme에도 접두사 없는 클래스(`chk-btn`)가 있다. Vtheme 결정 D85의 '접두사 = 프레임 범위 + 기본과 다른 모양'을 따른 것이다.
- 아이콘이 글자와 같은 색인 버튼(텍스트 버튼 등)은 아이콘 자리를 따로 두지 않는다. Figma에서는 아이콘에도 같은 글자색 변수를 연결한다(넥사크로에서는 아이콘이 이미지로 나간다).

## 5-2. 크기 · 글자 (`style` · `typo` 컬렉션)

값은 이미 정한 단계(값 의도 목록 '정한 것' 29~34번)를 옮긴 것이다. 색 표와 열이 달라 구조 지도에는 나오지 않는다.

- Vtheme 구성: `style`(gap · padding · radius)과 `typo`(font-size · font · font-weight · height)는 모드 3개(medium · large · Xlarge)를 가진다. 모바일 파일은 모바일 값 하나만 쓰므로 모드를 하나만 둔다(사용자 결정 2026-11-06).
- Vtheme은 단계 변수(`gap/g8` 등)에는 출력 이름을 두지 않고, 용도 이름이 붙은 변수(`radius/container-rad`, `padding/table-cell-pad`)에만 둔다. 아래도 같게 했다.
- 단계 이름의 숫자는 px 값이다. Vtheme도 15까지는 숫자가 px와 같고, 그 위(`g16` = 20)부터 어긋난다. 모바일 파일은 끝까지 px 숫자로 맞춘다(사용자 결정 2026-11-06).
